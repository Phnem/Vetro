# 0002 — Каталог книг: телефонный индекс V2 + API на Cloudflare

Статус: принято (2026-11-12). Подробности сборки — `book-dictionary/v2/README.md`, API — `tools/books-api/README.md`.

## Решение

Каталог книг — **первый источник** поиска и добавления аудиокниг: телефонный индекс → `api.vetrostudio.bid` →
аудио-источники (только за озвучкой). Название, автор, год и обложка берутся из каталога.

- Индекс на телефоне — SQLite **FTS4** (платформенный SQLite; FTS5 на Android не гарантирован), 31.7 МиБ,
  скачивается как zstd (10 МиБ), обновляется дельтами с проверкой SHA-256 и одной транзакцией на дельту.
- Опечатки — словарь индекса (`fts4aux`) + расстояние Дамерау — Левенштейна; ранжирование — `CatalogRanker`
  (хвост `book-catalog-rerank` под модель).
- Сервер — Worker + D1 (FTS5, 268 840 произведений с карточкой деталей в JSON) + R2 (индекс и обложки). Платный
  план Workers: D1 заливается за один заход.
- Книга без озвучки добавляется в библиотеку (`saveCatalogWork`), озвучка подцепляется позже
  (`BookSearchAdder.attachPending`, раз в 12 часов на книгу, пока открыт раздел «Книги»).

## Последствия и оговорки

- Обложки каталога — AVIF: системный декодер есть на Android 12+; на 8–11 обложка каталога пропускается, её ищут
  прежним `BookCoverFinder`.
- 70 537 из 88 110 обложек взяты с FantLab (реестр лицензий: `redistribution_allowed = 0`, только некоммерческое
  использование с атрибуцией). Раздача — решение владельца; в индексе остаётся флаг `f & 2`, в деталях —
  `cover.src/page/lic`, так что источник можно отключить без пересборки приложения.
- Индекс и сервер собираются одной нормализацией (`common.py` ⇄ `norm.js` ⇄ `BookNorm.kt`); меняя её, менять все
  три и `tests/golden_norm.json`.
- Мировой каталог без русских названий (≈1,5 млн) на сервер не выкладывается.
