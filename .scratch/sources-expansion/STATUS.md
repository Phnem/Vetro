Ключи попадают в `BuildConfig` и извлекаемы из APK — поэтому ограничение по пакету/подписи у
ключа Google обязательно. Квоты у ключей общие на всех пользователей (YouTube `search.list` —
100 запросов в сутки на проект, поэтому поиск YouTube приложение не использует). При росте
аудитории нужен серверный кэш/прокси (Supabase edge function) с общим кэшем ответов.

## Находки при проверке на устройстве

- Шаблон подстановок `\{([A-Za-z]+)}` роняет Android (ICU), хотя JVM его принимает — импорт
  манифестов v1 падал бы на телефоне. Исправлено во всех местах.
- Стрим-плеер строил источник только на OkHttp — субтитры из файла (`file://`) молча не
  показывались. Исправлено (`DefaultDataSource`).
- Google Books на ISBN «Задачи трёх тел» отдаёт сборник стихов — описание берём только при
  совпадении названия.
- Jikan прячет ошибку MAL в HTTP 200 (`{"status":500,"type":"UpstreamException"}`), а общий
  HTTP-кэш OkHttp держал такой ответ. Статус читается из тела, перед сбоем — один запрос мимо кэша.
- TasteDive для Breaking Bad предлагает «The Confession», «Smith», «The Fear», «Lone Star» —
  в «Похожее» не включаем.
