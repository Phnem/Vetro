# Проверка кейсов 1–10 из постановки

Status: resolved
Type: task

См. spec.md.

## Answer (28.09)

- Юнит-тесты (`BookAudioAlignerTest`, `TextSourcesTest`): кейсы 1 (та же редакция), 2 (пропуски чтеца),
  3 (цифры/слова, римские), 4 (вступление), 5 (другой перевод → отказ), 7 (прыжок далеко → re-sync),
  ошибки распознавания каждого 10-го слова, заполнение стыков, парсеры EPUB/FB2/TXT/cp1251, сопоставление авторов.
- Телефон (Xiaomi 13, `.perf`): синтетическая книга 27 мин + её `book.txt` в папке → «Свой файл», проба
  23 %, синхронизация 10 блоков, «Глава вторая» — 415,9 с (в записи 415,9 с); строка в плеере совпадает с речью.
  Кейс 8: процесс убит установкой — блоки сохранены, повторной пробы нет. Кейс 9: онлайн-озвучка
  «Задачи трёх тел» (2006 г.) — «Текст не найден», «Создать на устройстве» доступен отдельно.
- Не проверено на телефоне: «Создать на устройстве» для аудиокниг, реальная книга из Gutenberg/Викитеки
  (источники проверены curl'ом, не в приложении), кейс 6 (скорость) — по построению: поиск по шкале медиа.
