# Субтитры аудиокниги из текста книги (BOOK ↔ AUDIO alignment)

Постановка — пункт 14 бэклога 28.09 (`.scratch/backlog-2026-09-28/map.md`), полный текст пользователя
сохранён в истории сессии. Здесь — решения и границы первой версии.

## Два независимых источника субтитров

| Пункт меню | Что показывается | Хранилище |
|---|---|---|
| **Текст книги** | оригинальный текст книги, разбитый по предложениям; время — из выравнивания | `files/audiobooks/alignment/<variant-hash>/<text-hash>.json` |
| **Создать на устройстве** | распознанная речь (Whisper) — как у видео | `files/audiobooks/asr-subtitles/<variant-hash>.json` |

Не смешиваются ни в UI, ни на диске. Whisper-генерация сама не запускается, если текста нет.
Whisper внутри выравнивания — только инструмент (что и когда сказано), его текст не показывается.

## Конвейер

```
BookText (display) ─ BookTextNormalizer ─ предложения + BookTokenStream (matching, с offset'ами в display)
Аудио блоками 3 мин ─ Whisper (пословно) ─ TimedTranscript
BookTokenStream + TimedTranscript ─ BookAudioAligner ─ anchors ─ AlignedCue[] (предложения, confidence)
```

- **Нормализация** только для сравнения: lower, ё→е, NFC, кавычки/тире, числа → слова (RU/EN),
  римские → слова, «№» → «номер». Одна и та же функция для книги и для распознанного — Whisper пишет
  то «3», то «три».
- **Якоря**: совпадающие n-граммы (4 слова) распознанного и текста в окне вокруг ожидаемой позиции →
  цепочка возрастающих пар (LIS) → выбросы отбрасываются, одна ошибка не сдвигает книгу.
- **Окно**: ожидаемая позиция в тексте — по ближайшим якорям (время → символ); окно ±N слов, при
  потере синхронизации расширяется до ±15 % книги, затем до всей книги (re-sync).
- **Время предложения** — по якорям внутри него (пословные метки Whisper — акустика, не равномерная
  раскладка). Предложение без якорей между двумя сильными — MEDIUM, если темп правдоподобен; иначе LOW.
- **Confidence**: HIGH ≥ 0.5 доли слов предложения в якорях — показывать; MEDIUM — показывать только
  между двумя HIGH; LOW — не показывать (пустая строка лучше неверного текста).
- **Другой перевод / не та книга**: первые блоки дают < 12 % слов в якорях при поиске по всей книге →
  «Текст не совпадает с записью», выравнивание не продолжается.
- **Блоки** по 3 мин, сохраняются после каждого → возобновление после убитого процесса. Порядок:
  блок текущей позиции → вперёд до +30 мин → остальная книга (медленнее, только без перегрева и
  при заряде > 15 % или на зарядке). Скорость воспроизведения не влияет: всё на шкале медиа.
- **Кэш**: ключ = вариант озвучки + отпечаток треков + отпечаток текста + версия алгоритма. Сменился
  любой — файл не используется. Повреждённый файл — удаляется и считается заново.

## Поиск текста (по уже известным произведению и озвучке)

Источники (`BookTextSource`, список в DI, как у `AudiobookSource`), от точного к общему:
1. **Свой файл**: EPUB/FB2/TXT в папке локальной книги или выбранный вручную.
2. **LibriVox → Project Gutenberg**: для записей LibriVox `url_text_source` — ровно тот текст, что читали.
3. **Standard Ebooks** (EN, EPUB).
4. **Project Gutenberg** (OPDS-поиск, txt).
5. **Викитека** RU/EN (поиск API + EPUB через ws-export).
6. **Open Library → Internet Archive** (только `ebook_access = public`, `_djvu.txt`).

Отбор: название + автор (нечётко), язык озвучки, затем **проба содержимого** — 2 блока речи
(≈10 % и ≈50 % книги) должны заякориться в тексте, иначе кандидат отбрасывается.

## Вне первой версии

Пословная подсветка, открытие ebook на месте аудио, поиск по тексту, перенос прогресса ebook↔audio —
фундамент (якоря и отображение позиций) это позволяет.
