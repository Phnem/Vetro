# AB-05 — решение по источникам (2026-09-23)

Проверены 3 основных RU, 3 основных EN, два резерва, 4 якоря. Индивидуальные карточки с первичными URL — `research/sources/`; официальные источники якорей — `research/source-anchors.md`. В `app/src/test/resources/audiobooks/` сохранены robots.txt и компактные структурные JSON-снимки разрешённых публичных страниц/API. Аудиобайты и приватные токены не запрашивались.

| Роль | Итог |
|---|---|
| Первая полностью контролируемая проверка player/offline | Local Folder SAF в AB-09 |
| Первый онлайн-якорь | LibriVox + IA после проверки прав записи/региона и Range |
| Первый RU кандидат | Knigavuhe: поиск, детали, озвучки, сборник и настоящий restricted banner подтверждены; media resolve ещё неизвестен |
| Metadata only | Aknigi24: robots закрывает API и book media; Audiokniga.one: закрыт поиск и HLS; Akniga: закрыты stream/ajax, остальное не разведано |
| EN кандидаты | RealAudiobooks, Golden, 101: MP3 в HTML, но права/Range/стабильность не проверены; production stream пока выключен |
| Общая инфраструктура | Golden и 101 используют `ipaudio.club`; AudioAZ ведёт на `archive.org`, поэтому не независим от IA |
| Свой сервер | Audiobookshelf API устаревший по пометке документации; нужен contract test на реальном сервере |

**Непригодно для полного адаптера сейчас:** Audiokniga.one (автопоиск и HLS закрыты robots); Aknigi24 (media/API закрыты); Akniga (stream/ajax закрыты). Audioboo из старого плана не проверялся и остаётся выключенным, а не объявляется доказанно непригодным. Сайты с MP3 в HTML не автоматически допустимы для распространения: robots.txt и техническая доступность не устанавливают права на запись.

**Отклонения от полного AB-05:** HTML/медиа ответ не сохранялись целиком; JSON-файлы — структурные снимки для contract/design tests, а не готовые входы HTML-парсеров. AB-15 должен снять минимальные разрешённые HTML-узлы для MockEngine конкретного выбранного адаптера. Audiokniga.one search fixture отсутствует именно из-за robots.txt. Restricted fixture есть только для Knigavuhe, потому что другие проверенные страницы не содержали явного ограничения. Медиа Range/Referer/cookie/геодоступность и права отдельных записей оставлены для live smoke перед включением соответствующего `STREAM`/`DOWNLOAD`.

**Влияние на последовательность:** AB-17 должен выбрать первый пригодный RU источник через разрешённый media resolve; Knigavuhe — кандидат. Если этого пути нет, AB-17 ограничивается metadata, а первым полным онлайн-источником идёт LibriVox/IA. У AB-18 второй сайт выбирается только после подтверждения совместимой выдачи. Доказательство агрегации на двух разных сайтах остаётся обязательным до остальных адаптеров.
