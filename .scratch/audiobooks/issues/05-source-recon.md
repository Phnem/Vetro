# AB-05: Разведка источников и первые фикстуры

Status: done_with_deviations (2026-09-23)
Type: research
Blocked by: — (Q4/Q5 подтверждены пользователем)

## Цель

Для каждого источника из [spec/05 § Реестр](../spec/05-sources-and-aggregation.md#реестр-источников)
заполнить карточку в `research/sources/<source>.md` и сохранить фикстуры для тестов.

## Карточка источника

- Хосты: каталог, медиа, CDN → предполагаемая `InfrastructureGroup`.
- `robots.txt`: какие пути разрешены; какие страницы адаптеру нужны и разрешены ли они.
- Поиск: URL/метод, пагинация, что приходит (название, автор, чтец, обложка, длительность).
- Страница книги: метаданные, озвучки, главы/треки, где лежит список аудио (HTML, JSON-блок, API).
- Медиа: формат (MP3/M4B/HLS), нужны ли Referer/куки, срок жизни ссылок, поддержка Range.
- Признак «ограничено правообладателем» / «удалено» и как его распознать.
- Размер обложки, есть ли шаблон оригинала.
- Стабильность: 403/капча/геоблок — **если есть защита от ботов, источник помечается
  непригодным, обход не ищем**.
- Ожидаемые `Capability`.

## Объём

RU: Aknigi24, Audiokniga.one, Knigavuhe, Akniga (только метаданные), резерв — по времени.
EN: RealAudiobooks, GoldenAudiobooks, 101Audiobooks (подтвердить общую инфраструктуру), AudioAZ.
Якоря: LibriVox API, Internet Archive metadata, Audiobookshelf API (документация).

Фикстуры: по 1 запросу поиска, 2 страницы книги (обычная + сборник/несколько озвучек),
страница с ограничением правообладателя (если встречается), `robots.txt` —
в `app/src/test/resources/audiobooks/<source>/`.

## Критерии приёмки

- Карточки всех источников основной тройки RU и EN + якорей.
- Таблица реестра в spec/05 обновлена фактическими capabilities и группами.
- Список источников, признанных непригодными, с причиной.

## Результат

- Карточки 3 RU + 3 EN и дополнительных 101/Аkniga, а также четырёх якорей — `research/sources/`.
- Robots и компактные структурные фикстуры публичных поисков, двух книг на источник, сборника и реальной restricted-страницы — `app/src/test/resources/audiobooks/`.
- Реестр `spec/05` обновлён подтверждёнными/условными возможностями и инфраструктурными группами. Решение и список непригодных для полного адаптера — `reviews/05-source-recon.md`.
- Отклонения: для Audiokniga.one поиск не запрашивался из-за robots; raw HTML/медиа не сохранены; Audiobookshelf/live Local Folder и медиа Range требуют AB-09/AB-15/AB-16. Эти ограничения явны в review, а не скрыты за `STREAM` capability.
