## Реализация ближе к релизу

1. Использовать общий `CoverResolver`: при добавлении книги автоматически брать обложку источника, файл `cover`/`folder`/`front` рядом с локальными треками или встроенную обложку аудиофайла; при отсутствии — искать совпадение по автору/названию в разрешённых каталогах. Сохранять выбранный URL/URI и кэшировать изображение по `WorkId`. Для RU/EN записи выбирать соответствующие обложки, если они найдены. Не генерировать картинки и не вшивать набор из 14 статичных ассетов.
2. Создать каталог семи рекомендованных `Work` с устойчивыми UUID, языковыми названиями, авторами и порядком трилогии. Раздел «Рекомендуемые» должен показывать их как демонстрационную витрину, не подменяя личную коллекцию пользователя. Обложки загружать и кэшировать тем же механизмом; если права/источник или точное совпадение не подтверждены, показывать нейтральное состояние без выдуманной иллюстрации.
3. Для каждого языка и каждой книги сделать живой end-to-end smoke хотя бы одного разрешённого источника с реальным стартом воспроизведения и seek. Для современных книг эталон — собственный Local Folder или Audiobookshelf пользователя; внешние каталоги подключать только при подтверждённой доступности и правах конкретной записи. Если источник недоступен, показать честное состояние и путь «Добавить свой файл/сервер», не ссылку с ложным Play.
4. Проверить RU/EN переключение доступных обложек и названий, открытие Details, веер полки, fallback при недоступном варианте, offline-состояние и отсутствие лишних тестовых пакетов на Xiaomi. Финальный AB-38 прогон выполняется после этого тикета.

## Критерии приёмки

- Семь разных произведений, три книги Лю Цысиня в правильном порядке; обложки автоматически разрешаются из данных добавленной книги или каталога и кэшируются.
- Для каждого внешнего источника обложки документирован provenance; отсутствие совпадения не подменяется выдуманным артом.
- Рабочий источник подтверждён логом smoke для каждого реально доступного варианта; недоступные варианты не выглядят воспроизводимыми.
- Никакие полные аудиокниги не встраиваются в APK.
