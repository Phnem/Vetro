## Реализация ближе к релизу

1. Подготовить **две встроенные обложки для каждой книги**: русскую и английскую (14 assets), подходящие для карточек 2:3 и hero. Скачать обложки из источников с проверенным правом встраивания; сохранить URL, право использования, автора/издателя и дату в `assets/PROVENANCE.md`. Если внешнюю обложку встраивать нельзя, изготовить оригинальную альтернативу для соответствующего языка. Изображения оптимизировать и проверить размер APK.
2. Создать каталог семи рекомендованных `Work` с устойчивыми UUID, языковыми названиями, авторами, порядком трилогии и локальными обложками. Раздел «Рекомендуемые» должен показывать их как демонстрационную витрину, не подменяя личную коллекцию пользователя.
3. Для каждого языка и каждой книги сделать живой end-to-end smoke хотя бы одного разрешённого источника с реальным стартом воспроизведения и seek. Для современных книг эталон — собственный Local Folder или Audiobookshelf пользователя; внешние каталоги подключать только при подтверждённой доступности и правах конкретной записи. Если источник недоступен, показать честное состояние и путь «Добавить свой файл/сервер», не ссылку с ложным Play.
4. Проверить RU/EN переключение обложек и названий, открытие Details, веер полки, fallback при недоступном варианте, offline-состояние и отсутствие лишних тестовых пакетов на Xiaomi. Финальный AB-38 прогон выполняется после этого тикета.

## Критерии приёмки

- Семь разных произведений, три книги Лю Цысиня в правильном порядке, 14 локальных обложек.
- Для каждого ассета документирован provenance и проверена сборка/размер.
- Рабочий источник подтверждён логом smoke для каждого реально доступного варианта; недоступные варианты не выглядят воспроизводимыми.
- Никакие полные аудиокниги не встраиваются в APK.
