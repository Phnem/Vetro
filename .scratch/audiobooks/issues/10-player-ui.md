# AB-10: Мини-плеер и полный плеер

Status: implementing
Type: implementation
Blocked by: AB-03, AB-08, AB-09

## Цель

Один корневой `AudiobookPlayerHost` управляет живой Media3-сессией: мини-плеер остаётся поверх навигации, раскрывается в полный, показывает главу и прогресс, управляет воспроизведением и возвращается в мини без потери позиции.

## Приёмка

- Одна сессия `MediaController` в корне UI; локальная книга показывает мини-плеер после запуска и полный плеер после тапа. Состояние переживает закрытие полного экрана и меняется при системных media controls.
- −15/+30, play/pause, seek главы, скорость 0,5–3,0 с пресетами, список глав. Не создавать MediaController на каждый тап.
- Полный player по spec/10: обложка/placeholder, затемнённый фон, верхняя навигация, название, глава, chapter clock, тихий book progress, крупные доступные кнопки.
- Анимация одного хоста mini ⇄ full, жест вниз/Back; путь от Books/Details origin. 20 циклов на Xiaomi без краша, физический frame gate 0 кадров >32 мс после warmup.
- Release compile, Android smoke service/UI, сохранение resumption для логического `vetro-audio` URI; текущая release feature gate закрыта до M1.

## Границы

Таймер, закладки, умный откат, пропуск тишины — AB-11. Реальная страница audiobook Details — AB-29: до неё origin проверяется с локальной карточки и существующего Details-механизма. Реальные обложки витрины — AB-39.

## Промежуточное состояние 2026-09-24

### Коррекция пользователя после просмотра на Xiaomi

- Свёрнутый плеер — **квадратная плавающая карточка** над доком справа по умолчанию, по образцу `references/img/mini-square-user-reference-2026-09-24.png`. Её можно перетаскивать; после отпускания она магнитится к ближайшему из четырёх углов безопасной области.
- Раскрытие и сворачивание должны идти **из геометрии этой карточки и обратно в неё**. Уезд полного экрана вниз не соответствует референсу и не принимается.
- Полный экран по `references/img/player-user-reference-2026-09-24.png`: иллюстрация во весь экран, тёмный низ под текстом, название и автор, оранжевый прогресс, крупные круглые −15/play/+30, четыре нижних действия. Повторить композицию почти в точности, заменяя только то, что требует audiobook-функциональность.
- Текущий экран «Книги» с одной кнопкой — временная заглушка. Дом по видео-референсу остаётся обязательным результатом AB-29; не выдавать заглушку за готовый дизайн.
- `app/src/main/res/drawable-nodpi/audiobook_demo_space.png` — сгенерированная тестовая иллюстрация без UI, только для разработки визуала. Реальные локализованные обложки и рабочие источники — AB-39.

Корневой хост подключён к Media3 через application context, чтобы при уничтожении Activity не было повторного `unbindService`. Мини/полный экран, play/pause, −15/+30, chapter seek, скорость и chapter clock работают с реальной локальной очередью; временный resume-store теперь сохраняет всю очередь логических `vetro-audio://` URI, текущий индекс и позицию. Эмулятор API 37: 1 AndroidTest прошёл, включая разворачивание, паузу, сохранённую очередь из двух файлов, переход к следующей главе, скорость 1,5× и сворачивание; снимки `reviews/assets/ab10-player-*-emulator.png`.

Xiaomi 2211133C: мини/полный плеер с локальной двухтрековой очередью виден и управляется; три серии по 20 циклов без падения. Убрано покадровое пересоздание структуры хоста: позиция вынесена в отдельный `State<Long>`, пороги раскрытия — в `derivedStateOf`, оболочка и траектория placeholder-обложки рисуются в draw-фазе, полный контент обрезается по движущейся оболочке. AndroidTest на эмуляторе API 37 повторно прошёл после изменения морфа. Последний снимок полного экрана: `reviews/assets/ab10-final-full.png`; промежуточный кадр: `reviews/assets/ab10-shell-art-mid.png`.

Физический frame gate **не пройден**: последний `gfxinfo` после warmup — 3826 кадров, 0 deadline-jank, но 44 кадра в histogram строго >32 мс (`reviews/assets/ab10-phone-20cycles-art-shell.txt`). Вариант без обрезки и перелёта обложки дал 34/3810, но выглядел хуже в середине перехода. Debug APK и release Kotlin compile прошли; первый release-прогон столкнулся с очисткой `processReleaseResources` во время параллельной сборки, повтор с одним Gradle worker прошёл. Критерий плана — именно 0 кадров >32 мс, поэтому AB-10 остаётся `implementing`. Остаются: профилирование этих медленных кадров, настоящий origin с карточки/Details, реальная обложка и кэшированный фон, жесты и accessibility, динамический заголовок M4B главы в шторке. Эмулятор при `adb install -r` показывает предупреждение о 16 KB page-size для двух библиотек; тест закрывает его через доступность, а release-проверка вынесена в AB-38.
