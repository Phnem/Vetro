# 06 · Офлайн (AB-34)

## Движок

Media3 `DownloadManager` + свой `AudiobookDownloadService : DownloadService` (D-14).

- `DownloadManager(context, databaseProvider, downloadCache, dataSourceFactory, executor)`;
  `downloadCache` — тот же `SimpleCache`, из которого читает плеер (`filesDir/audiobooks/media`).
- `dataSourceFactory` — `VetroAudioDataSource.Factory`: загрузчик тоже получает свежие URL и
  заголовки через `vetro-audio://` (подпись истекла в середине загрузки → перерезолв).
- `DownloadRequest.id = "<variantId>/<track>"`, `customCacheKey = то же`, `data` = JSON
  `{workKey, narrationKey, chapterRange}` для UI.
- Планировщик — `WorkManagerScheduler` (`media3-exoplayer-workmanager`): загрузки ждут сеть/Wi-Fi
  и переживают перезагрузку.
- `Requirements`: `NETWORK` или `NETWORK_UNMETERED` (настройка «Только Wi-Fi», по умолчанию вкл.),
  `DEVICE_STORAGE_NOT_LOW`.
- Параллелизм: 2 трека одновременно; на один хост — не больше 1 (rate-limit из spec/05).
- Сервис: `foregroundServiceType="dataSync"` (разрешение уже есть). Уведомление —
  `DownloadNotificationHelper` с каналом «Загрузки аудиокниг», заголовок = книга, прогресс по книге.
  На Android 15 у `dataSync` лимит ~6 ч в сутки: большие очереди продолжаются на следующий день
  (показываем «Пауза: лимит системы»).

## Что можно скачать

| Выбор | Что ставится в очередь |
|---|---|
| Книга целиком | все треки выбранного варианта |
| Главы | треки, которые пересекаются с выбранными главами. Если книга — один файл (M4B), выбор глав недоступен, подсказка «Книга — один файл, скачивается целиком». |
| «Следующие N глав» (быстрая кнопка) | треки ближайших N глав от текущей позиции |

Какой вариант качать: первый по `FallbackPlan` с `Capability.DOWNLOAD`/`STREAM`, у которого
резолв успешен. Скачанный вариант получает высший приоритет в плане fallback навсегда (пока не
удалён).

## Офлайн-воспроизведение

- Плеер читает `CacheDataSource` → скачанное играет без сети.
- Манифест скачанного варианта (треки, длительности, главы) сохраняется в SQL
  (`audiobook_chapter`) и в `ManifestCacheStore` без срока — книга открывается без сети.
- Обложка и палитра — в `ImageStorageRepository` / `CoverPaletteStore` (не из сетевого кэша Coil).
- Частично скачанная книга: скачанные главы играют, на нескачанной без сети — пауза + «Нет сети,
  эта глава не скачана».

## UI

- Детальная страница: кнопка «Скачать» → лист «Книга целиком / Выбрать главы / Следующие 5 глав»
  (паттерн шагов — как `DetailsDownloadSheet`, но короче) → прогресс-кольцо на кнопке.
- Список глав: иконка состояния у каждой (нет / в очереди / круговой прогресс / скачано / ошибка).
- Полка «Скачанные» на доме; бейдж на обложке.
- Настройки раздела: занятое место, «Только Wi-Fi», «Удалить все загрузки», удаление по книге.
- Удаление книги из коллекции спрашивает, удалить ли загрузки (урок манги: «глобальной уборки
  нет» — здесь уборка обязательна: `AudiobookStorageJanitor` при удалении и раз в неделю
  сверяет кэш с БД и удаляет осиротевшее).
