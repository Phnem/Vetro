## Юнит-тесты (JVM, `app/src/test/.../audiobooks/`)

| Область | Что проверяем |
|---|---|
| `TitleNormalizer` | таблица реальных заголовков с сайтов (из фикстур AB-05): шум убран, номер тома вынесен, авторы в разных форматах сводятся |
| `WorkClusterer` / `NarrationMerger` | склейка/несклейка: сборник vs произведение, один чтец — две записи, «чтец не указан», пограничные длительности 2,9 % / 3,1 % |
| `BookTimeline` | toGlobal/toTrack на границах треков, главы внутри одного файла, неизвестные длительности, `remainingMs` со скоростью |
| `PositionMapper` | все 4 правила spec/03 |
| `FallbackPlan` | исключение Restricted/Removed/выключенных, чередование инфраструктурных групп, скачанный вариант первый, userPinned |
| Здоровье | сбой хоста пишет источнику и группе, PARSE — только источнику; выученный отпечаток объединяет источники |
| `SleepTimer`, `SmartRewind` | виртуальное время (`TestScope`), «конец главы», пауза/возобновление |
| `RobotsPolicy` | запрет пути блокирует запрос, кэш на сутки |
| Guard'ы `MediaType.AUDIOBOOK` | каждый воркер/юзкейс обогащения и синка не трогает AUDIOBOOK-строку |
| Адаптеры источников | Ktor `MockEngine` + фикстуры: search/details/chapters/resolve, Restricted-страница, изменённая разметка → `Failed(PARSE)`, а не краш |
| Миграция 16 | схема применяется на копии БД версии 15 (тест SQLDelight-миграций, как у существующих `.sqm`) |

`@LiveSource`-тесты (ручные, вне CI) — по одному на адаптер: живой поиск по эталонному запросу,
проверка, что разметка не поменялась.

## Бюджеты производительности

| Что | Бюджет | Как мерим |
|---|---|---|
| Морф веер→полка, мини⇄полный | 60 fps, 0 кадров > 32 мс на среднем устройстве | `adb shell dumpsys gfxinfo`, JankStats на отладочной сборке |
| Первый кадр дома «Книги» | ≤ 300 мс после перелистывания (данные из БД, обложки — плейсхолдеры) | Macrobenchmark не заводим; логируем `reportFullyDrawn`-подобную метку |
| Память полного плеера | обложка ≤ 1600 px, фон — миниатюра; ни одного bitmap > 8 МБ | Profiler |
| APK | + ≤ 1,5 МБ (media3-ui-compose, workmanager-интеграция, blurhash) | сравнение `assembleRelease` |
| Батарея | фон 1 ч с выкл. экраном ≤ ~3 % на средней батарее | Battery Historian по желанию |

## Критерии готовности тикета (Definition of Done)

1. `./gradlew :app:compileDebugKotlin -q` и тесты тикета зелёные.
2. Если тронуты строки/DI/манифест/Media3 — `:app:assembleRelease` и запуск release-APK.
3. `git diff --stat` = `git diff --ignore-cr-at-eol --stat` (переводы строк не переписаны).
4. Нет захардкоженных `spring(...)`/альф стекла; новые — в `MotionTokens`/`FrostedMaterials`.
5. Строки только в `AudiobookStrings`.
6. Запись в `EXECUTION_LOG.md` и обновлённый `CURRENT_HANDOFF.md`.
