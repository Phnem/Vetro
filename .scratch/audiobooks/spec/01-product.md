# 01 · Продукт: что получает пользователь

Источники: [`../references/raw/tecplan.txt`](../references/raw/tecplan.txt),
[`../references/raw/desplan.txt`](../references/raw/desplan.txt).

## Суть

Аудиокниги — пятый тип контента Vetro. Пользователь находит книгу, выбирает чтеца, слушает онлайн
или офлайн, а Vetro помнит место в каждой книге, показывает прогресс, закладки и статистику —
так же естественно, как для аниме и манги.

Три ощущения, ради которых всё делается:

1. **Библиотека, а не список.** Дом «Книги» — полки с обложками, которые живут и двигаются.
2. **Одна книга — одна карточка.** Дубли из пяти сайтов не видны; видно «3 озвучки».
3. **Плеер, который не надо ждать.** Мгновенный старт с места, где остановился; если источник
   упал — книга продолжает играть с другого, пользователь этого не замечает.

## Глоссарий раздела

| Термин | Значение | Не путать с |
|---|---|---|
| **Произведение (Work)** | Книга как текст: название + автор(ы). Одна карточка в UI. | изданием, файлом |
| **Озвучка (Narration)** | Конкретная запись произведения конкретным чтецом (или составом). | источником |
| **Вариант (ProviderVariant)** | Одна и та же озвучка на конкретном сайте/сервере. Невидим пользователю. | озвучкой |
| **Манифест** | Разрезолвленный набор аудиофайлов варианта с длительностями и заголовками. Живёт недолго. | вариантом |
| **Глава** | Логическая отметка на шкале книги. Не обязана совпадать с файлом. | треком/файлом |
| **Трек** | Один аудиофайл манифеста. | главой |
| **Шкала книги** | Сквозное время озвучки от 0 до полной длительности. В ней хранится позиция. | позицией в файле |
| **Полка** | Подборка книг на доме «Книги» (Продолжить, Серии, Автор…). | коллекцией Vetro |

Термины вносятся в корневой `CONTEXT.md` при первом тикете (через `/domain-modeling`).

## Пользовательские сценарии V1

### С1. Найти и начать слушать
Поиск → вкладка «Аудиокниги» → карточка «Мастер и Маргарита · Булгаков · 3 озвучки» → детальная
страница → чип чтеца (по умолчанию лучший по доступности и длительности) → «Слушать» → обложка
перелетает в плеер, звук идёт через ≤ 2 с на хорошей сети.

### С2. Продолжить
Открыл приложение → на доме «Книги» первым блоком «Продолжить» → «Продолжить» на карточке →
мини-плеер появляется снизу и играет с сохранённого места (с «умным откатом» на 5–30 с, если
пауза была долгой).

### С3. Слушать в фоне
Свернул приложение / заблокировал экран → звук продолжается; в шторке и на lockscreen — системный
media-control: обложка, название, глава, play/pause, −15/+30, прогресс. Кнопки гарнитуры работают.
После убийства процесса системный «продолжить» в шторке поднимает книгу с места.

### С4. Сменить чтеца
На детальной странице или в плеере → «Озвучка» → список чтецов с длительностями → выбор → место
переносится по главе (или по доле книги, если разметка глав различна) с предупреждением.

### С5. Уснуть под книгу
Плеер → «Сон» → 15/30/45/60 мин или «до конца главы» → последние 10 с — затухание громкости →
пауза. Встряхнуть телефон во время затухания — продлить на 5 мин (опционально, см. spec/10).

### С6. Скачать в дорогу
Детальная страница → «Скачать» → книга целиком или выбранные главы → прогресс в списке глав →
без сети книга играет, отметка «скачано» на полке «Скачанные».

### С7. Закладка
В плеере → «Закладка» (долгое нажатие — с заметкой) → список закладок в листе глав → тап → переход.

### С8. Своя папка
Настройки источников / пустое состояние дома → «Добавить папку с книгами» → SAF → книги из
подпапок появляются в библиотеке с главами (M4B-главы или файлы по порядку).

## Функциональные требования

| Область | Требование V1 |
|---|---|
| Плеер | −15 с / play-pause / +30 с по умолчанию; назад и вперёд независимо настраиваются на 10/15/30/60 с; скорость 0,5×–3,0× шагом 0,05 с пресетами, главы, закладки, таймер сна, «глава N из M», процент книги, «осталось 3 ч 42 мин» (с учётом скорости), пропуск тишины (опция). |
| Фон | `MediaLibraryService`, шторка/lockscreen, BT/проводные кнопки, audio focus (звонок/навигация → пауза/приглушение), «becoming noisy» → пауза, возобновление после убийства. |
| Мини-плеер | На всех экранах Vetro над доком; тап/свайп вверх → полный плеер; свайп вниз по мини — закрыть (стоп + сохранить). |
| Библиотека | Книга в коллекции (рейтинг, избранное, теги, заметка), позиция отдельно на каждую озвучку, закладки, процент, статистика прослушивания. |
| Источники | RU-тройка, EN-тройка, локальная папка, Audiobookshelf, LibriVox; включение/выключение и порядок в настройках источников. |
| Агрегация | Параллельный поиск, одна карточка на произведение, озвучки внутри, варианты скрыты, динамический приоритет, fallback по инфраструктуре. |
| Офлайн | Книга целиком / главы; только Wi-Fi (опция); занятое место; удаление; офлайн-воспроизведение. |
| Поиск | Вкладка «Аудиокниги»; секции «Книги», «Авторы», «Чтецы». |
| Локализация | RU/EN во всём разделе. |

## Нефункциональные требования

| Метрика | Цель |
|---|---|
| Старт воспроизведения онлайн (кэш манифеста тёплый) | ≤ 1,0 с до звука |
| Старт онлайн (холодный резолв) | ≤ 2,5 с p50, ≤ 6 с p90 |
| Старт «Продолжить» офлайн | ≤ 400 мс |
| Потеря позиции при убийстве процесса | ≤ 10 с |
| Кадры на морфе веер→полка и мини⇄полный | 60 fps на среднем устройстве, без кадров > 32 мс |
| Fallback при падении источника посреди книги | ≤ 3 с тишины, позиция сохранена |
| Батарея при фоновом прослушивании с выключенным экраном | без wake-lock'ов сверх `WAKE_MODE_NETWORK` во время стрима |

## Вне рамок V1

- Синхронизация прогресса аудиокниг с внешними трекерами (у Shikimori/AniList/MAL их нет).
- Текст книги / синхронный текст-аудио.
- Платные источники, логины на сайтах, DRM (Audible, Storytel, ЛитРес-подписка).
- Chromecast / Wear OS (Android Auto — опциональный AB-37).
- Эквалайзер, «усиление голоса» (кроме пропуска тишины).
- Импорт библиотек из других приложений.
- Mihon-подобные устанавливаемые расширения-источники (граница `AudiobookSource` это позволит позже).
