# 09 · Детальная страница книги

Референсы: существующий `ui/details/DetailsScreen.kt` (структура), desplan §2, tecplan §3.

## Принцип

«Почти 1-в-1 с Details аниме/фильма» (tecplan) **и** «большая центрированная обложка на
размытом фоне» (desplan) совмещаются так: берём **двухзонную структуру** существующего Details
(закреплённый hero + лист контента со скруглённым верхом, наезжающий при скролле, мини-док с
пейджером), но hero для книги — не растянутый арт, а центрированная обложка.

Маршрут: `AudiobookDetailsRoute(workKey: String, collectionId: String? = null)` в `Routes.kt`.
Переход — как у Details (iOS-push справа, скругление 42 dp при закрытии и predictive back, Home
«вдавливается»), **плюс** перелёт обложки из места тапа (если прототип AB-03 подтвердит
совместимость `sharedElement`-обложки с `layerBackdrop` мини-дока; иначе — push без перелёта и
перелёт только в плеер).

## Композиция

```text
┌──────────────────────────────┐
│ (‹)                    (♡)(⋯)│  ← стеклянные кнопки как DetailsGlassBackButton
│   размытая обложка на весь hero (σ 40, затемнение 45 %)
│          ┌────────┐          │
│          │ обложка│  18 dp   │  ← 56 % ширины, тень elevation.2
│          │  2:3   │          │
│          └────────┘          │
╞══════════════════════════════╡  ← лист контента, радиус 30, наезжает при скролле
│ Мастер и Маргарита           │  28sp
│ Михаил Булгаков              │  → тап: полка автора
│ ( Герасимов ✓ )( Клюквин )( +1 )   ← чипы озвучек
│ 16 ч 52 мин · 32 главы · 1967 · RU │  ← мета-строка
│ [ ▶ Слушать ]  [ ⤓ ]  [ ＋ ]  │  ← главная — оранжевая; скачать; в библиотеку/в очередь
│ Цикл: … №2 →                 │
│ Описание… (раскрытие)        │
│ Главы  ▸ 1. …  2. …  3. …    │  ← превью 5 глав, «Все главы» → страница 2
│ Озвучки (подробно)           │
│ Похожие книги  [к][к][к] →   │
└──────────────────────────────┘
          [ Инфо | Главы ]       ← мини-док (как DetailsMiniDock)
```

- Страница 1 «Инфо» — всё выше. Страница 2 «Главы» — полный список (как `ModernDetailsEpisodesPage`
  для серий): номер, название, длительность, отметка прослушанного (галочка / частичное кольцо),
  иконка загрузки, текущая глава подсвечена; закладки — отдельной секцией сверху, если есть.
- Кнопка «Слушать» меняет текст: «Слушать» → «Продолжить · Глава 7» → «Слушать заново».
- Неготовые данные (главы ещё резолвятся) — скелетоны строк, не спиннер на всю страницу.

## Озвучки — «главная фишка» (desplan §2.3)

- Чипы: имя чтеца (или «Состав» / «Радиоспектакль»), активный — заливка поверхности + галочка.
  Больше 3 — «+N» открывает лист.
- Лист «Озвучка» (по паттерну Set Status: карточки-опции): чтец(ы), длительность, число глав,
  тип (сокращённая/полная/TTS), индикатор доступности («доступно офлайн», «доступно», «временно
  недоступно», «недоступно у источника по запросу правообладателя»). **Источники не
  показываются** — только в «⋯ → Технические детали» (для отладки: список вариантов, здоровье,
  «открыть на сайте»).
- Смена озвучки при наличии прогресса — подтверждение с объяснением, куда переедет позиция
  (правила PositionMapper, spec/03).

## Действия

| Действие | Где | Поведение |
|---|---|---|
| Слушать | главная кнопка | резолв через FallbackPlan → плеер раскрывается из обложки hero (обложка перелетает в плеер, закон 1) |
| Скачать | кнопка ⤓ | лист выбора из spec/06; на кнопке — кольцо прогресса |
| В библиотеку | кнопка ＋ (если не в коллекции) | создаёт запись коллекции (AB-33), кнопка превращается в ✓ |
| В очередь | «⋯» | добавить после текущей книги (очередь книг — V1 минимальная: одна «следующая») |
| Избранное | ♡ | как у записи коллекции |
| Отметить прослушанной | «⋯» | `finished = 1` |
| Редактировать | «⋯» | AddEdit (минимальный: название, теги, заметка, рейтинг) |

## Карточка книги в коллекции Vetro

Если книга в коллекции (`MediaType.AUDIOBOOK`), тап по её карточке на Home коллекции ведёт на
**эту** страницу (ветка в месте, где сейчас `navigateToDetails(id)`), кнопка карандаша — на
AddEdit, как у остальных типов.

## Переиспользование кода

Кандидат на вынос из `DetailsScreen.kt` (1031 строка) в `ui/shared/components/DetailsScaffold.kt`:
закреплённый hero + параллакс, лист с перекрытием (`BoxWithConstraints` + `heightIn(min)`),
мини-док с пейджером (`DetailsMiniDock`/`MiniDockItem`), стеклянные кнопки. Решение в AB-31:
выносим, если копия > ~300 строк; при выносе поведение Details аниме не меняется (скриншоты
до/после).
