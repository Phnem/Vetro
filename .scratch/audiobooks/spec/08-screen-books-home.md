## Композиция

К релизу добавить отдельную редакторскую полку из семи книг пользователя: трилогия Лю Цысиня
(`Задача трёх тел`, `Тёмный лес`, `Вечная жизнь Смерти`), `Ложная слепота`, `Марсианин`,
`Солярис`, `Свидание с Рамой`. Каждая получает локальные RU/EN название; обложку приложение
получает автоматически из источника или каталога при добавлении книги и кэширует. Полка
не добавляет книги в персональную коллекцию без действия пользователя. Реальные источники
и состояние доступности проверяются в AB-39 перед финальным AB-38 QA.

### Контекстный подзаголовок

Выбирается по приоритету: «N книг в процессе» → «На этой неделе: 4 ч 20 мин» → «Продолжите
историю» → пусто. Меняется кросс-фейдом.

### Блок «Продолжить»

- Главная крупная карточка — последняя по `audiobook_progress.updated_at` незаконченная книга;
  ниже горизонтальный ряд следующих 2–4.
- Показывает: обложку, название, автора, чтеца, текущую главу «Глава 7 из 42», кольцо/полосу
  прогресса (заливка `BrandOrangeBright`), «осталось» с учётом скорости книги, одну CTA.
- CTA «Продолжить»: микро-анимация нажатия (press → snappy), затем мини-плеер выезжает снизу, а
  обложка карточки **перелетает** в миниатюру мини-плеера (origin → мини; закон 1).
- Самый «живой» блок: обложка первой книги задаёт цвет атмосферы дома.

### Полки

Каждая полка на доме — **карточка с веером из 3 обложек** (как «коллекции» из видео), тап →
страница полки. Набор (скрываются, если пусты):

| # | Полка | Источник данных | V1? |
|---|---|---|---|
| 1 | Продолжить | `audiobook_progress` | да (отдельный блок выше) |
| 2 | Подобрано для вас | авторы/чтецы/жанры из прослушанного + «похожие» у источников | AB-36 |
| 3 | Автор: X | авторы с ≥ 2 книгами в библиотеке (по одной полке на топ-3 автора) | да |
| 4 | Серии | произведения с `series_title` | да |
| 5 | Новое в библиотеке | коллекция, `dateAdded` за 30 дней | да |
| 6 | Скачанные | загрузки | AB-34 |
| 7 | Чтецы, которых вы любите | `audiobook_listen_session` по чтецам | AB-36 |
| 8 | Сборники и антологии | `is_collection` | да |
| 9 | Отложено | тег/флаг «слушать позже» в коллекции | да |
| 10 | Прослушано | `finished = 1` | да |

Карточка полки: подложка `IosDesign.rowBackground`, радиус 24; сверху слева «◷ обновлено N назад»,
справа счётчик книг; по центру название и подзаголовок; ниже веер из 3 обложек: крайние повёрнуты
на ∓5°, перекрытие ~30 %, средняя поверх и на 4 dp выше; веер обрезан нижним краем карточки
(ровно как на видео). Между полками 14 dp.

Горизонтальный ряд используется только для «Продолжить». Остальные подборки в V1 —
анимированные карточки-полки с веерами; переключателя вида нет.

### Карточка книги (общий примитив `CoverCard`)

- Обложка 2:3, радиус 10, двухслойная мягкая тень; под ней 2 строки названия и 1 строка автора
  (на полках-рядах — только обложка + прогресс-полоска снизу обложки).
- Тап → детальная страница (обложка летит, см. spec/09).
- Долгое нажатие → контекстное меню-«вылет» из точки касания (паттерн `TtmMenu`/`WebLinkPopupMenu`):
  «Слушать», «Скачать», «В отложенные», «Отметить прослушанной», «Убрать из библиотеки».
  Фон — скрим, карточка приподнимается (scale 1,03), как у карточек коллекции Vetro.

### Пустые состояния

- Библиотека пуста: иллюстрация-стопка из трёх пустых «корешков» + «Найдите первую книгу» →
  поиск книг; вторая кнопка «Добавить папку с аудиокнигами» (SAF).
- Нет сети и нечего играть офлайн: подсказка про «Скачанные».

## Страница полки

Референс: [`video-06-shelf-page.jpg`](../references/img/video-06-shelf-page.jpg).

```text
        ━━  (грэббер — лист, свайп вниз закрывает)
        Автор: Пелевин
        7 книг · 64 ч
   [⌕ Искать на полке ]            ← фильтр по полке, не глобальный поиск
   Лучшее на полке
   [к][к][к][к][к] →               ← горизонтальный ряд книг «на планке»
   ═══════════════════════════     ← планка
   Все
   [ к ][ к ]                      ← сетка 2 колонки, крупные обложки
   [ к ][ к ]
```

- «Лучшее на полке»: для авторских — по рейтингу пользователя, для «Продолжить» — по свежести,
  для остальных — первые 8.
- **Планка** — `ShelfPlank`: полоса 6 dp под рядом, цвет `BrandTan` α 0,22 на тёмном, верхняя
  кромка 1 физ. px светлее (+8 % белого), под ней мягкая тень 8 dp вниз. Книги стоят на ней
  нижним краем (без зазора).
- Док рабочей области прячется (`WorkspaceDock(hidden = true)`) и возвращается при выходе.
- Закрытие: свайп вниз по листу (прерываемый, `MotionTokens.willDismiss`), системное «назад»,
  predictive back (прогресс жеста ведёт обратный морф).

### Маршрут или слой?

AB-04 выбрал **слой внутри страницы «Книги»**. Морф веер→полка видит обе раскладки одновременно,
а страница пейджера рабочей области остаётся в композиции. На Xiaomi вариант A после прогрева дал
0 кадров >32 мс за 8 раскрытий и 8 закрытий; маршрут `NavHost` + `sharedElement` дал 32 и 36.
Слой нужно держать скомпонованным в закрытом состоянии (`alpha=0`, без semantics и перехвата
касания): пересоздание при каждом открытии не прошло кадровый порог.

## Морф «карточка-полка → страница полки» (главный переход)

Референс: [`video-04-card-to-shelf-strip.jpg`](../references/img/video-04-card-to-shelf-strip.jpg),
[`video-05-card-to-shelf-midframe.jpg`](../references/img/video-05-card-to-shelf-midframe.jpg).

Все траектории — одна `Animatable<Float> progress` 0→1 (`shelfExpand()`), из которой каждый
элемент считает свой transform; жесты пишут в тот же `progress` (прерываемость).

| t | Элемент | Движение |
|---|---|---|
| 0 | карточка-полка | подложка карточки растёт к границам экрана (scale+translate `graphicsLayer`; в финале радиус 24→40 (лист)); остальные карточки: opacity 1→0 за 140 мс + translationY +12 dp |
| 0 | обложки веера (3 шт.) | из веерной позы (поворот ∓5°, перекрытие) в позы ряда полки: поворот → 0, x → место в ряду, y → строка полки, scale → размер ряда; каждая со сдвигом `staggerStepMs` (средняя первой) |
| 0,1 | обложки 4…8 ряда | которых не было в веере — появляются из-за правого края (translationX +24 dp → 0, opacity) каскадом |
| 0,15 | заголовок карточки | переезжает вверх в заголовок страницы: **один** текст, `graphicsLayer` translate; размер шрифта не анимируется — масштабирование текста 0,85→1 допускается только как transform, если новый размер ≤ 1,2× (иначе кросс-фейд двух текстов) |
| 0,2 | «◷ …» и счётчик | гаснут (EaseExit) |
| 0,35 | планка | проявляется: scaleX 0,6→1 от центра + opacity |
| 0,45 | строка поиска полки, «Все», сетка | fadeEnter + translationY 24 dp → 0, каскад строк сетки |
| 0,5 | док | уходит вниз (его собственная анимация `hidden`) |

Обратный переход — `shelfCollapse()`: контент страницы гаснет первым (EaseExit 100 мс), обложки
возвращаются в веер своей карточки, карточки списка проявляются. Скролл дома сохраняется; если
карточка-полка ушла за экран, пока открыта страница, — обложки летят к ближайшему краю и гаснут.

Производительность: финальная раскладка страницы полки измеряется **один раз**; во время морфа
меняются только `graphicsLayer`-параметры (правило `scaleToBounds`, память
`glass-menu-header-and-transition-perf`). Бюджет — 60 fps на среднем устройстве (AB-04).

## Док и поиск

- Кнопка поиска дока на странице «Книги» открывает **поиск книг** (вкладка «Аудиокниги»
  предвыбрана). Нужна доработка `WorkspaceSearchState`: заявка несёт целевую страницу.
- Кнопка ⌕ в шапке дома делает то же самое.
- Меню «⋯»: сортировка полок, вид полок, «Добавить папку», настройки источников книг.
