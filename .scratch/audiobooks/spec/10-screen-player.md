# 10 · Плеер и мини-плеер

Референс: [`../references/img/player-reference.png`](../references/img/player-reference.png)

## Что в референсе и как переносим

| В референсе | В Vetro Audiobook Player |
|---|---|
| Портрет артиста на весь экран, тёмно-оранжевый тинт | **Большая обложка книги** по центру + фон из неё же (размытый, тинт из палитры обложки → к чёрному снизу) |
| Название и артист слева внизу над контролами | Название, автор · чтец, «Глава 7 из 42 · Название главы» — слева внизу |
| Правая колонка из 3 маленьких круглых стеклянных кнопок | Колонка: «Главы», «Закладка», «Озвучка» (или «Скорость») — `playerChip`, круглые 40 dp |
| Прогресс в стеклянной капсуле со временем по краям | Капсула `playerTrack`: прошло слева, **осталось в главе** справа; метки глав на полосе (если глав ≤ 60) |
| 3 больших круглых стеклянных кнопки: prev / pause / next | −15 / play-pause / +30, `playerControl`, 72 dp (центральная 84 dp); иконки перемотки с цифрой внутри |
| Сверху: назад-шеврон слева, действие справа | ⌄ (свернуть в мини) слева, «⋯» справа (скачать, таймер, пропуск тишины, поделиться, детали книги) |

## Композиция полного плеера

```text
┌──────────────────────────────┐
│ (⌄)                     (⋯)  │
│                              │
│        ┌──────────────┐      │
│        │              │      │  ← обложка 78 % ширины, радиус 18,
│        │   обложка    │      │     тень elevation.2, «дыхание» при игре
│        │              │      │
│        └──────────────┘      │
│                         (≡)  │  ← колонка chip-кнопок справа, вровень с низом обложки
│ Мастер и Маргарита      (🔖) │
│ Булгаков · Герасимов    (🗣) │
│ Глава 7 из 42 · «Понтий Пилат» │
│ ( 12:40 ▓▓▓▓▓░░░░░ −18:03 )  │  ← стеклянная капсула прогресса ГЛАВЫ
│ 38 % книги · осталось 10 ч 12 мин │ ← тихая строка
│   (↺15)    ( ❚❚ )    (30↻)   │  ← три стеклянные кнопки
│ ( 1.2× )( Сон 30 )( Главы )( Озвучка ) │ ← утилитарный ряд glass-чипов
└──────────────────────────────┘
```

- Прогресс-бар показывает **главу** (длинная книга на одной полосе бесполезна); книжный прогресс —
  строкой ниже и тонкой полосой под обложкой (опция). Переключение «глава/книга» — тап по
  правому времени.
- Скраббинг: бегунок — белый круг 15 dp (как в видеоплеере), при перетаскивании превью времени
  и названия главы над пальцем; «снап-бэк» лечится `pendingSeek` (приём из `PlayerScreen.kt`).
- Долгое нажатие на −15/+30 — перемотка к началу/концу главы (с подтверждающей вибрацией).
- Чип скорости показывает текущее значение; чип «Сон» — оставшееся время таймера (обратный
  отсчёт), иначе «Сон».

## Фон и атмосфера

- Слой 0: обложка, растянутая на экран, размытая (σ 60 статически, **не анимируется**), затемнённая
  градиентом сверху-вниз: 30 % → 85 % чёрного.
- Слой 1: тинт из доминантного цвета палитры обложки (α 0,35), `animateColorAsState` при смене книги.
- Слой 2: мягкое зерно (тот же `NoiseTile`, что у FrostedGlass) против бандинга градиента.
- Этот стек пишется в `layerBackdrop` плеера; стеклянные кнопки сэмплируют его — поэтому стекло
  «живое» даже над статичным фоном (под ним переливы размытой обложки, а не сплошной цвет).
- Цвет системных баров — прозрачный, иконки светлые.

## Мини-плеер

```text
[ обл. | Мастер и Маргарита          | ❚❚ | ↻30 ]
[ 44dp | Гл. 7 · осталось 18 мин     |    |     ]
 ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔ тонкая полоса прогресса главы по нижней кромке
```

- Капсула 64 dp, материал `miniPlayer`, над доком с зазором 8 dp; на экранах без дока (Details,
  полка) — у нижнего края с отступом навигационной панели.
- Тап / свайп вверх → раскрыть; свайп вниз → закрыть (стоп + сохранить, тост «Остановлено» с
  «Вернуть»); горизонтальный свайп → ±30 с (с подсказкой-иконкой).
- Скрывается: в видеоплеерах (они — отдельные активити), в ридере манги (отдельная активити),
  при открытой клавиатуре, при раскрытом полном плеере.
- Появление — выезд снизу `menuPop()` + fade; если запуск был с карточки, обложка перелетает в
  миниатюру.

## Мини ⇄ полный: один объект (D-04, прототип AB-03)

`AudiobookPlayerHost` живёт в корне UI (`AppNavGraph`, над `NavHost`, внутри
`SharedTransitionLayout`, но **без** `sharedBounds` вокруг себя):

- `expand: Animatable<Float>` 0 (мини) → 1 (полный), пружины `playerExpand()`/`playerCollapse()`.
- Геометрия оболочки интерполируется между прямоугольником мини-плеера и экраном; радиус 22 → 0
  (на полном — радиус экрана устройства при сворачивании, как у Details).
- Обложка — отдельная траектория: прямоугольник миниатюры → прямоугольник hero-обложки; радиус
  8 → 18.
- Контент полного плеера (тексты, контролы) — `fadeEnter` после `expand > 0,55`, каскад строк
  24 мс; при сворачивании гаснет первым (`EaseExit`), до того как оболочка начнёт сжиматься
  (раздельные траектории, UNIVERSAL_MOTION_SPEC §5).
- Контент мини-плеера гаснет при `expand ∈ [0; 0,2]`.
- Жест: вертикальный драг по полному плееру пишет прямо в `expand` (rubber-band за пределами),
  отпускание — `MotionTokens.willDismiss` по смещению и скорости; predictive back ведёт `expand`.
- Раскрытие из **другой** точки (обложка Details, карточка «Продолжить»): хост принимает
  `originRect` (механизм `stagedMorphOrigin` / `LocalStagedMorphOrigin` уже есть в
  `ui/shared/StagedSheetMotion.kt`) и первая траектория обложки начинается оттуда.
- Под раскрытым плеером приложение «вдавливается» (scale 0,94 + скругление) — тот же приём, что
  `homePushProgress`; не забыть флаг в `overlayActive`/`effectsSettled`
  (`GlassBackdropRecovery`, память `layerbackdrop-invalidation-gotcha`).

Почему не маршрут: полный плеер как destination NavHost требует `sharedBounds` от мини-плеера,
а у плеера свой `layerBackdrop` → известный SIGSEGV в RenderThread.

AB-03 подтвердил геометрию одного корневого хоста и 20 циклов без краша на Xiaomi, но
абсолютный бюджет 0 кадров >32 мс не достигнут (18/2966 кадров без видеозаписи). В AB-10
перед переносом прототипа в main: перелёт из настоящей Details, кэш размытой реальной обложки,
профилирование стеклянных контролов и повторный физический frame gate. Сокращение перекрытия
мини/полного контента в прототипе ухудшило замер и было отменено.

## Листы плеера

Все — `MotionBottomSheet`/`IosSheetScaffold` поверх плеера (Z 40 над 45 → листы плеера рисуются
внутри хоста выше его контента), поверхность `IosDesign.sheetSurface`, без кромок, скрим.

| Лист | Содержимое |
|---|---|
| Главы | поиск по главам; список с длительностью, прогрессом, иконкой загрузки; текущая — подсвечена и прокручена в центр; секция «Закладки» с заметками и «＋ Закладка здесь» |
| Скорость | крупное значение, слайдер 0,5–3,0 шагом 0,05 с «прилипанием» к пресетам 0,8/1,0/1,2/1,5/2,0; пресеты-чипы; переключатель «для этой книги / для всех»; «Пропуск тишины» |
| Сон | 5/10/15/30/45/60, «Конец главы», своё; активный таймер — кольцо обратного отсчёта, «Отменить», «+5 мин»; «Затухание» и «Встряхнуть, чтобы продлить» |
| Озвучка | как на детальной странице (spec/09) |
| ⋯ | Скачать, Детали книги, Поделиться (ссылка на страницу источника/название), Технические детали (вариант, источник, здоровье — для отладки) |

## Движение во время игры

- «Дыхание» обложки (`coverBreathing`) — только когда играет и экран на переднем плане; пауза →
  плавная остановка в нейтраль (не рывок).
- Play/pause: иконка морфит (❚❚ ↔ ▶) кросс-фейдом + scale 0,9→1 `standard()`; кнопка
  «продавливается» (press).
- Прогресс двигается плавно: позиция интерполируется между тиками плеера (тик 250 мс, отрисовка
  каждый кадр по `withFrameMillis`), без дёргания бегунка.
- Смена главы: название главы — вертикальный слайд старого вверх/нового снизу (8 dp) + fade.
- Reduced motion: без дыхания, без морфа иконки, кросс-фейды 100 мс.

## Доступность

- Все кнопки ≥ 48 dp зоны касания, `contentDescription` на RU/EN, озвучка значений
  («Скорость 1,2», «Осталось 18 минут в главе»).
- Слайдер прогресса — семантика `ProgressBarRangeInfo` + действия «вперёд 30 с/назад 15 с».
- Контраст текста над фоном-обложкой ≥ 7:1 обеспечивается затемняющим градиентом (проверка на
  светлых обложках — в AB-35).
