# 12 · Обложки и атмосфера (AB-27)

desplan §5: «без нормальных cover images весь player рассыпется». Плеер и детальная страница
показывают обложку почти на всю ширину — нужен минимум 1000 px по большей стороне, желательно
1200–1600 px.

## CoverResolver — каскад

```text
1. при добавлении локальной книги: `cover`/`folder`/`front` рядом с треками → единственное изображение в папке → встроенная обложка первых трёх аудиофайлов; сохраняем URI/кэш для плеера и полок
2. обложки всех вариантов кластера (онлайн-источники) → берём самую большую по заявленному/фактическому размеру
3. повышение разрешения у самого источника: известные шаблоны URL превью → оригинал
   (например, /thumb/ → /original/, суффиксы размера) — правила в адаптере, не в резолвере
4. если лучшая < 1000 px — внешний поиск по «название + автор (+ ISBN, если известен)»:
   a. iTunes Search API (entity=audiobook): artworkUrl100 → замена размера на 1400x1400bb
   b. Open Library Covers (по ISBN / olid из search.json) — размер L
   c. Google Books volumes (imageLinks, параметр zoom) — последний, качество нестабильное
   сопоставление: совпадение автора (фамилия) + сходство названия ≥ 0,8 (тот же нормализатор)
5. ничего лучше нет → лучшая из имеющихся + «апскейл-подложка»: обложка по центру в слоте на
   фоне из самой себя, размытой (не растягиваем мелкую картинку на весь hero)
```

Внешние API — публичные и бесплатные; результаты кэшируются по постоянному `WorkId` на 30 дней
(`CoverDescriptorCacheStore` — уже есть похожий стор, проверить переиспользование).
Пользователь может выбрать обложку вручную из найденных кандидатов («⋯ → Сменить обложку»).
Точно подходящая обложка берётся из данных книги; сгенерированные изображения не используются.

## Что хранится

| Поле | Где | Зачем |
|---|---|---|
| исходный URL лучшей обложки | `audiobook_work.cover_url` | повторная загрузка |
| большая копия (≤ 1600 px, WebP q85) | `ImageStorageRepository` (для записи коллекции — `imageFileName`) | детали, плеер, офлайн |
| миниатюра (≤ 400 px) | кэш Coil / файл рядом | полки, мини-плеер, шторка |
| палитра: dominant, darkVibrant, vibrant, muted | `audiobook_work.cover_palette_json` | атмосфера дома и плеера, тинт |
| blurhash (4×3) | `audiobook_work.cover_blurhash` | мгновенный плейсхолдер до загрузки картинки |

Палитра — `androidx.palette` (уже в каталоге) на миниатюре 128 px, вне главного потока.
Цвет тинта ограничивается по яркости (L в HSL 0,18–0,45) и насыщенности, чтобы кислотные обложки
не превращали плеер в неон; ахроматичные обложки → `BrandTan`.

Blurhash — маленький кодер/декодер (≈ 100 строк, без зависимости) в `audiobooks/covers/`.

## Где что используется

| Экран | Изображение |
|---|---|
| Полки, поиск | миниатюра + blurhash-плейсхолдер |
| Детали — hero-обложка | большая копия |
| Детали — фон hero | миниатюра, размытая σ 40 (размытие статичное) |
| Плеер — обложка | большая копия |
| Плеер — фон | миниатюра, размытая σ 60, + тинт палитры |
| Мини-плеер | миниатюра |
| Шторка / lockscreen | большая копия через `BitmapLoader` сессии (системе нужно ≥ 512 px) |
| Дом — атмосфера | только цвет из палитры (без картинки) |

## Квадратные и нестандартные обложки

Аудиокниги часто квадратные (1:1). Слот обложки — 2:3; квадратная обложка вписывается целиком
(fit), слот заполняется размытой копией этой же обложки с затемнением 20 %. Никакого кропа.
