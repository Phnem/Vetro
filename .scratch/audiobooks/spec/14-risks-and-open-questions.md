## Правовые рамки

Это не юридическая консультация, а инженерные ограничения, которые я заложил в план, и риски,
о которых стоит знать.

- **Большинство сайтов из плана** (RU-тройка и резерв, EN-тройка и 101Audiobooks) распространяют
  коммерческие аудиокниги без явной лицензии. Технически адаптеры к ним ничем не отличаются от
  остальных, но риск держателя приложения — реальный.
- **Дистрибуция.** Vetro распространяется через GitHub Releases / Obtainium / F-Droid. У F-Droid
  есть правила включения и анти-фичи; приложение со встроенными адаптерами к пиратским каталогам
  может получить пометку или быть снято. Смягчение: адаптеры сайтов изолированы за
  `AudiobookSource` и включаются в настройках источников (выключены по умолчанию или с
  предупреждением — решает пользователь); законные якоря работают всегда.
- **Границы доступа**: нет обхода антибот-защиты, капч, DRM, авторизации или `robots.txt`
  (поэтому Akniga — только метаданные). При заявленном ограничении конкретный вариант
  исключается, а агрегатор ищет независимо доступную ту же озвучку у других источников.
  У каждого нового источника действуют собственные условия доступа.
- **Нагрузка на сайты**: rate-limit на хост, кэш выдачи и манифестов, никаких фоновых массовых
  обходов каталогов — только запросы, инициированные пользователем (поиск, открытие книги,
  воспроизведение, скачивание).

## Технические риски

| Риск | Вероятность | Влияние | Смягчение |
|---|---|---|---|
| Апгрейд Media3 ломает видео (HLS, ABR, PiP, скачивание) | средняя | высокое | гейт AB-02 до любого кода раздела, SMOKE_MATRIX видео, откат одной строкой версии |
| Kotlin 2.1.0 несовместим с метаданными Media3 1.11.x | низкая–средняя | среднее | проверка в AB-02; при необходимости — апгрейд Kotlin отдельным шагом |
| `sharedElement`-обложка внутри экрана с `layerBackdrop` → SIGSEGV | средняя | высокое | D-04 (плеер без sharedBounds), прототип AB-03; для деталей — перелёт обложки только если прототип зелёный |
| Сайты меняют разметку / закрываются | высокая | среднее | фикстуры + `@LiveSource`, `Failed(PARSE)` → здоровье → тихий уход вниз, несколько источников на язык |
| Протухающие ссылки на медиа | высокая | среднее | `vetro-audio://` + `ResolvingDataSource`, ключ кэша не зависит от URL |
| Неверная склейка разных книг / разбиение одной | средняя | среднее | консервативные пороги, «разделить/объединить» в «⋯ → Технические детали» (V2), ИИ-арбитр опционально |
| Разные нарезки одной записи → сдвиг позиции при fallback | средняя | среднее | шкала книги + PositionMapper + тост «место приблизительное» |
| Старые клиенты и `AUDIOBOOK` в облаке | высокая, если синк включить сразу | высокое | Q3: локальные audiobook-строки до совместимого релиза |
| Лимит `dataSync` FGS на Android 15 | средняя для больших книг | низкое | Requirements + продолжение на следующий день, понятное сообщение |
| Утечка памяти от больших обложек в плеере | низкая | среднее | лимит 1600 px, фон из миниатюры |
| Раздувание `UiStrings` → VerifyError в release | низкая (правило известно) | высокое | `AudiobookStrings`, release-проверка в DoD |
| Смешанные LF/CRLF дают «файл переписан» в diff | средняя | низкое | правило из памяти `mixed-line-endings-gotcha`, проверка в DoD |
