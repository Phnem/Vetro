# Аудиокниги — папка раздела

Всё про пятый тип контента Vetro Collection в одном месте: план, спецификации, референсы,
тикеты. Начинать с [`MASTER_PLAN.md`](./MASTER_PLAN.md).

```text
audiobooks/
├── README.md                ← вы здесь
├── MASTER_PLAN.md           цель, решения, вехи, все тикеты AB-01…AB-38, команды проверки
├── CURRENT_HANDOFF.md       состояние работы для следующей сессии
├── EXECUTION_LOG.md         журнал выполненного
├── references/
│   ├── REFERENCES.md        все референсы с путями на ПК
│   ├── VIDEO_BREAKDOWN.md   покадровый разбор видео с полками
│   ├── raw/                 копии исходных планов (tecplan.txt, desplan.txt)
│   └── img/                 референс плеера + кадры видео
├── spec/                    01 продукт · 02 архитектура · 03 модель и БД · 04 движок ·
│                            05 источники · 06 офлайн · 07 визуальный язык · 08 дом и полки ·
│                            09 детали · 10 плеер · 11 поиск · 12 обложки · 13 качество ·
│                            14 риски и вопросы
└── issues/                  тикеты фазы 0 (AB-01…AB-05); следующие фазы нарезаются при старте
```

## Как этим пользоваться

1. Q1–Q8 уже подтверждены и записаны в [`spec/14`](./spec/14-risks-and-open-questions.md#решения-пользователя).
2. Пройти фазу 0 (гейты): AB-01 завершён; AB-02 остаётся открытым до полного video smoke;
   затем AB-03/04/05. До закрытия AB-02 audiobook-код не писать.
3. Дальше — по вехам M1…M7 из мастер-плана; тикеты фазы кладутся в `issues/NN-slug.md`
   (конвенция `docs/agents/issue-tracker.md`), статус — строкой `Status:`.
4. После каждого тикета — запись в `EXECUTION_LOG.md` и обновление `CURRENT_HANDOFF.md`.
