# RU-источники: проверка 2026-09-26

Проверено вживую: поиск → страница книги → плейлист → Range-запрос к MP3. Подключено шесть сайтов
в дополнение к Aknigi24. Приоритет (витрина, озвучки, запасные при запуске) — порядок ниже.

| # | Сайт | Поиск | Главы и длины | Звук | Срок ссылок |
|---|------|-------|---------------|------|-------------|
| 1 | aknigi24.com | HTML | JSON плеера, длины есть | прямые MP3 | бессрочно |
| 2 | yakniga.org | открытый GraphQL `/graphql` (`search(term)`) | `book(id){chapters{…}}`, длины есть | прямые MP3 `/files/…` | бессрочно |
| 3 | audiokniga.one | форма DLE (POST) | `playerInit(…, 'json', [...])`, длины есть; метаданные — schema.org | S3 readsound.ru | бессрочно |
| 4 | knigavuhe.org | HTML `/search/?q=` | `new BookPlayer(id, [...])`, длины есть | подписанные MP3 | `url_refresh_in` (~3,5 дня) |
| 5 | baza-knig.info | `/search?text=` | Playerjs `….pl.txt` (JSON), длин нет | CDN redirectto.cc, нужен Referer сайта | бессрочно |
| 6 | slushat-knigi.com | форма DLE | тот же Playerjs/CDN, что у baza-knig (зеркало) | как у baza-knig | бессрочно |
| 7 | audioknigi.fun | форма DLE | AJAX `mod=audioplaylist`, длин нет | подписанные MP3 slovushko.com | `expires=` (~сутки) |

Длины треков без данных сайта раскладываются по общей длине книги со страницы пропорционально
размерам файлов (HEAD, Content-Length) — главы на шкале книги и прогресс работают.

Не подключены:
- **akniga.org** — звук выдаётся по токену плеера с шифрованием ответа; обход защиты сайта не делаем.
- **knigavuhe-audio.com** — ссылки на звук намеренно обфусцированы; не декодируем.
- **audioboo.org, booktracker.org** — только торренты, потокового звука нет.
- **flibusta.su, fantasy-worlds.ru** — только ознакомительные фрагменты ЛитРеса.
- У Knigavuhe лицензионные книги — тоже фрагмент ЛитРеса: такая озвучка `Restricted`, запуск и
  страница книги сами уходят на тот же текст на другом сайте.
