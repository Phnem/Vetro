# 08 · Плашка «источник умер» не исчезает после восстановления

Status: implemented (не проверено на устройстве)

## Симптом
Пропал интернет → «Источник больше не отвечает» → связь вернулась, видео играет, а плашка
висит поверх кадра. Помогает только перезаход.

## Причина
`playbackError` в `StreamPlayerActivity` ставится, когда перерезолв ссылки не нашёл замену,
и снимается только руками пользователя или следующим переключением. Если исходный поток
ожил сам, плашку снимать некому.

## Решение
Снимать плашку по факту возобновления воспроизведения (`onIsPlayingChanged(true)`) и не
ставить её вовсе, если к моменту провала перерезолва плеер уже играет.
