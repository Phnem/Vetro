# Vetro v3.3.5-Beta — заметки к релизу

Черновик, пополняется по этапам плана (`План-v3.3.5-Beta`). Замеры — Xiaomi 13, 120 Гц,
`dumpsys gfxinfo framestats`, RenderThread+GPU p50/p90 и доля кадров длиннее 16,7 мс.

## Исправления

- Проверка обновлений с GitHub больше не считает любой релиз новее: заглавная «V» в версии
  приложения разбиралась как мажорная версия 0.

### Почему лагал свайп страниц (этап 3)

1. Стекло внутри страниц (шапка настроек, кнопка «Поделиться», доки главной) получало колбэк
   позиции на каждом кадре «наезда» и заново пересчитывало размытие. Во время движения пейджера
   стекло теперь «привязано» (`PinnableBackdrop`): смещение относительно своего бэкдропа не
   меняется, пересчёт не нужен.
2. Слой страницы перерисовывался целиком, и сквиркл-скругления настроек под масштабом уходящей
   страницы Skia растеризовала на CPU с загрузкой текстуры (~12 загрузок на кадр). Содержимое
   страницы теперь в offscreen-слое.
3. Тень наезжающей страницы — градиентом вместо `shadowElevation` на весь экран.
4. Цепочки стекла запоминаются (`remember`): рекомпозиция больше не пересобирает RenderEffect и
   тень.
