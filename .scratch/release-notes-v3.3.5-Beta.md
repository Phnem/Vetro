# Vetro v3.3.5-Beta — заметки к релизу

Замеры плавности — Xiaomi 13, 120 Гц, `dumpsys gfxinfo framestats`: RenderThread+GPU p50/p90 и доля
кадров длиннее 16,7 мс. Замеры старта и размеров — эмулятор Pixel 10 Pro (API 37, страницы 16 КБ),
коллекция из одного тайтла; на реальной коллекции выигрыш этапов 9 и 11 больше.

## Что изменилось для пользователя

- **Один режим интерфейса.** Новый интерфейс включён по умолчанию; в настройках разработчика
  остался один переключатель «Классический интерфейс».
- **Свайп назад в Деталях.** Жест слева направо на странице «Детали» закрывает экран, как в iOS.
- **Прокрутка как в iOS** во всех списках: инерция UIScrollView и «резинка» на краях.
- **Колокольчик уведомлений.** Стопка новых серий на холодном старте при первом действии
  сворачивается в колокольчик рядом с доком; по нажатию — центр уведомлений из матовых карточек,
  «Очистить всё» убирает их и помечает прочитанными.
- **Плеер.** Боковые кнопки (Пропустить, Вернуть, меню) — белая рамка, текст и иконка, без
  подкрашивания под сцену. Подписи плеера на языке приложения, а не системы.
- **Кнопка «наверх»** на главной — матовая, как остальные элементы нового интерфейса.
- **Один «зелёный».** Брендовый зелёный #34C759 для всего «готово/просмотрено/скачано».
- **Промо плеера V3.3.3 убрано.**
- **Значки статус-бара** над артом в Деталях белые (раньше сливались с картинкой).
- **Android 16 и 16 КБ страницы:** приложение больше не запускается в режиме совместимости.

## Исправления

- Проверка обновлений с GitHub считала любой релиз новее (заглавная «V» в версии).
- Ключ Gemini уходил в URL и в логи запросов — теперь в заголовке, логи сети только в отладке.
- Гонка при открытии БД на старте (два драйвера — «застывший» список).
- Фоновое обслуживание коллекции гоняло одни и те же тайтлы по кругу; отметки «не найдено» на MAL
  затирались.
- Синхронизация: ошибка выгрузки маскировалась успешной загрузкой; для гостя периодика будила
  воркер каждые 15 минут впустую.
- Кнопка, чипы поиска и стрелка «назад» были почти невидимы на матовом стекле в светлой теме;
  тёмная полоса у правого края главной в покое.
- Проверка новых серий могла идти двумя каскадами одновременно (главная + фоновый воркер).
- Резолвер сезонов на тайтлах, которых нет в каталогах, проходил по сети всю коллекцию за прогон.

### Почему лагал свайп страниц (этап 3)

1. Стекло внутри страниц получало колбэк позиции на каждом кадре «наезда» и заново пересчитывало
   размытие. Во время движения пейджера стекло «привязано» (`PinnableBackdrop`).
2. Сквиркл-скругления под масштабом уходящей страницы Skia растеризовала на CPU (~12 загрузок
   текстур на кадр). Содержимое страницы теперь в offscreen-слое.
3. Тень наезжающей страницы — градиентом вместо `shadowElevation` на весь экран.
4. Цепочки стекла запоминаются: рекомпозиция не пересобирает RenderEffect и тень.

### Остальное по этапам

- **Главная и оверлеи (4, 8):** анимации читаются в фазах раскладки/отрисовки, а не в
  композиции — шторки, колоды карточек, сплэш, сегмент-контрол, список серий, блюр настроек
  (фиксированный радиус, проявляется прозрачностью).
- **Плеер (7):** позиция больше не пересобирает экран 4 раза в секунду; прогресс пишется раз в
  10 с при воспроизведении и сразу на паузе (было — каждую секунду, даже на паузе); сторож
  буферизации работает только во время буферизации.
- **Буфер стрима (7):** 60/90 с по времени как раньше; ограничитель по памяти включается, только
  если 90 с потока не влезают в кучу, и никогда не ниже 60 с — на 0,5–2 Мбит/с не включается.
- **Загрузки (7):** HLS — до 3 сегментов параллельно без двойной записи на диск; прогресс
  публикуется только при смене процента.
- **Источники (7, 9):** Kodik отменяемый; точная ссылка и остальные источники — одной параллельной
  пачкой; один пул соединений на всё приложение, таймауты каталога 15–60 с вместо 5 минут.
- **Старт (9):** миграции хранилища не держат сплэш на каждом запуске; координаторы фона стартуют
  через 5 с; БД не трогается на главном потоке; одна подписка на коллекцию вместо пяти.
- **Фон (9):** ссылки «Где смотреть» — только текущий язык, пустые результаты с растущим
  интервалом, запись файла раз на пачку.
- **Код (9–10):** ~4,6 тыс. строк мёртвого кода удалено; общие JSON/Левенштейн/повтор 429/порядок
  франшизы; ast-grep-правила (`scripts/lint-ui.sh`) держат iOS-прокрутку во всех контейнерах.
- **Сборка (11):** узкие правила R8; `Log.d/v` вырезаются в релизе; `profileinstaller` — профили
  библиотек (Compose и др.) теперь применяются и при установке не из Play; модуль `:baselineprofile`
  готов, профиль пути пользователя ещё не сгенерирован (`:app:generateReleaseBaselineProfile` с
  подключённым телефоном).
