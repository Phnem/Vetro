# Whisper на устройстве — исследование и решения (27.09.2026)

Цель: «Создать субтитры локально на устройстве» — звук текущего видео распознаётся на телефоне,
ничего не уходит на сервер, результат кэшируется.

## Что измерено на Samsung S25+ (Snapdragon 8 Elite)

| Что | Результат |
|---|---|
| Звук из HLS (публичный тестовый поток), 60 с → 16 кГц моно | 5,5 с с сетью (≈11× быстрее реального времени) |
| Звук из файла по http (jfk.wav, 11 с) | 0,45 с, длина ровно 11,0 с |
| Загрузка модели tiny (32 МБ) с докачкой | CDN Hugging Face отвечает 206 на Range; SHA-256 совпал; 2,8 с |

Распознавание ещё не измерено: нужен собранный whisper.cpp (NDK, см. «Сборка»).

## Модели (whisper.cpp, многоязычные, q5_1)

| Модель | Размер | Роль |
|---|---|---|
| small-q5_1 | 190,1 МБ | по умолчанию: заметно лучше base на русском |
| base-q5_1 | 59,7 МБ | для устройств с 4–6 ГБ ОЗУ или <8 ядер |
| tiny-q5_1 | 32,2 МБ | минимальная: <3 ГБ ОЗУ, не arm64, <6 ядер |

Хеши закреплены в `WhisperModel`; файл с другим хешем не используется. Англоязычные `.en`-модели
не берём: нужен русский. q8_0 (small — 264 МБ) почти не лучше q5_1 по качеству, но тяжелее.

Выбор модели — `WhisperDeviceProfile.recommended(RAM, ядра, arm64)`; если выбрана тяжелее
рекомендованной — меню показывает лёгкую рядом. После первого куска менеджер сравнивает время
распознавания с длиной куска: медленнее видео — подсказка перейти на лёгкую модель.

## Ускорение

- **CPU (NEON) — основной путь.** Сборка с `armv8.2-a+dotprod+fp16`: dotprod ускоряет квантованные
  матричные умножения в разы; есть на всех 64-битных SoC примерно с 2018 года.
- **GPU (Vulkan / OpenCL у ggml)** — на Android пока экспериментально и зависит от драйвера
  Adreno/Mali; в первой версии не включаем. Точка для замера после сборки.
- **NPU (QNN / NNAPI)** — whisper.cpp не поддерживает; NNAPI в Android 15+ объявлен устаревшим.

## Потоки, батарея, нагрев

- Потоки: `ядра − 1`, не больше 6 (интерфейс и плеер не голодают; дальше ~6 прирост мал на
  big.LITTLE — малые ядра тормозят общую синхронизацию).
- Распознавание — пачкой по минуте звука, а не непрерывно: между кусками процессор отдыхает;
  при остановке плеера работа продолжается в `AppScope`, пока жив процесс.
- Нагрев и батарея — после сборки замерить на серии 24 мин; при `THERMAL_STATUS_SEVERE`
  (PowerManager) приостанавливать распознавание — следующий шаг.

## Реальное время против предварительной генерации

- Выбрано: **предварительно, но с текущего места.** Первым распознаётся кусок с позицией
  зрителя, дальше — к концу серии, потом начало. Реплики показываются поверх кадра по мере
  готовности, без пересборки источника плеера.
- Потоковое «синхронно с воспроизведением» у Whisper даёт задержку в несколько секунд и рваные
  фразы (окно модели — 30 с), поэтому не выбрано.
- «Только текущий диапазон» получается само: пользователь может остановить после первых кусков —
  готовое остаётся в кэше, продолжение распознаёт только недостающее.

## Приватность и хранение

- Звук не покидает устройство: извлечение и распознавание — локально, сеть только для самого видео.
- Модель — `filesDir/whisper` (удаляется из настроек «Источники → Субтитры на устройстве»),
  готовые субтитры — `filesDir/whisper-subtitles`, временный звук — `cacheDir`.
- Ключ кэша: серия + озвучка (разные озвучки — разная речь) + язык + модель.

## Сборка

whisper.cpp — сабмодуль `app/src/main/cpp/whisper.cpp` (закреплённый тег), JNI —
`app/src/main/cpp/vetro_whisper.cpp`, CMake — `app/src/main/cpp/CMakeLists.txt`, Kotlin —
`WhisperCppEngine` (без `libvetro_whisper.so` сообщает «недоступно в этой сборке»). Для сборки нужны
Android NDK и CMake из SDK Manager; ABI — только `arm64-v8a` (размер APK: +1–2 МБ библиотеки).
